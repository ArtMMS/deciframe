# DesvendaMe

Uma experiência web interativa baseada em mistério, enigmas e interação com o usuário.

O projeto tem como objetivo criar uma experiência imersiva diretamente no navegador, explorando entrada do usuário, efeitos visuais, animações e diferentes respostas às ações realizadas durante a experiência.
