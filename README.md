# DesvendaMe

Uma experiência web interativa baseada em mistério, enigmas e interação com o usuário.

O projeto tem como objetivo criar uma experiência divertida diretamente no navegador, explorando entrada do usuário, efeitos visuais, animações e diferentes respostas às ações realizadas durante a experiência.


## 🛠️ Tecnologias

# Linguagens
- HTML
- CSS
- JavaScript

# APIs
- Web APIs — interação com o navegador
- Web Audio API — efeitos sonoros
- CSS Animations — efeitos visuais e transições
